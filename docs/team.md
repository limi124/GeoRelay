# 团队分工

| 负责人 | 职责 | 可验收交付 |
| --- | --- | --- |
| 项目负责人 | Web 全栈、核心功能与最终联调 | 路网与任务接口、内涝事件、增量重调度、Agent 模拟执行与状态回写 |
| Bubble | Web 前端优化 | 三维地图交互、受阻原因与候选对比面板、Agent 模拟轨迹和任务状态。先用样例数据开发，随后接入接口 |
| 野有茶 | 测试与验收 | 固定演练案例，验证 Agent 接单、受阻与完成是否正确回写；整理缺陷复现记录和静态基线对照数据 |

接口或样例数据发生变更，在对应 PR 里说明，并同步给受影响的成员。缺陷至少记录场景、复现步骤、预期、实际结果，有条件时附截图或录像。
