# 首版范围与验收

首版收敛为一个预置小区、一次内涝、一次跨端改派。用固定案例验证，避免每次演示依赖临时配置。

- [ ] 行前：甲组向 3 号楼送物资；另有一条任务不经过即将封闭的路段。
- [ ] 触发：增大降雨，目标路段达到阈值后受阻。指挥端能查看水深与阈值。
- [ ] 求解：给出甲组绕行和乙组从备用点接手两个可比较方案；无关任务保持原安排。
- [ ] 确认：负责人选中乙组接手后，乙组手机显示新任务。
- [ ] 回报：手机接单、确认完成；指挥端更新状态并保留改派记录。
- [ ] 对照：使用同一初始场景与灾情输入，分别运行静态基线和增量重调度，记录需求覆盖率、时限违约数及重算任务占比。

**交付顺序：** 先用固定封路事件联通桌面和手机，再接入内涝推演，最后做对照验证及演示排练。火灾、地震、自然语言上报和自动建模留到主链路稳定之后。
