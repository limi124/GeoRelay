# 首版范围与验收

首版在一个 Web 指挥台完成「用自己的社区模型跑一次内涝 + 一次改派」。志愿者由 Agent 模拟，调度建议须经指挥员确认。

状态标记：`[x]` 已实现并通过自动化验证，`[~]` 已实现但依赖外部凭据才能验证真实接口，`[ ]` 未做。

## 一、社区建模

- [x] 定位社区：定位到我 / 地址搜索 / 手动选址；定位被拒绝、不可用、超时都有具体提示与继续操作的入口。
- [x] 电子围栏：绘制（点击加点、双击结束）、编辑顶点、撤销、重画；校验面积与自交；**凹多边形可用**。
- [x] 三维楼栋：批量生成（数量 / 默认层数 / 单层层高），围栏内尽量均匀；可选中、拖动、增删、改单栋层数与层高。
- [x] 楼栋校验：整栋底面不出围栏、不与其他楼栋重叠；空间不足时提示可容纳数量与调整建议。
- [x] 独立楼栋图层 + 背景楼块开关（并说明「高德不支持按多边形局部隐藏」的限制）。
- [x] 最小路网：标记大门 / 楼栋入口 / 物资接驳点，生成示例连线并确认；不把楼间空隙当道路；统一坐标系与稳定 ID。
- [x] 本地保存，刷新恢复。

## 二、指挥台与图层

- [x] 同一地图实例切入指挥台（不重建地图），镜头平滑聚焦社区，编辑工具退出。
- [x] 三个一键视图（全局 / 社区内部 / 外部支援），共享同一份演练状态与当前选中任务；切换不丢进度。
- [x] 待确认路线（橙色虚线）与已生效路线（绿色实线）线型区分 + 图例。
- [x] 接驳点显示「待到达 / 待交接 / 已接力」。
- [x] 未接入真实数据的库存、起点、轨迹明确标注为演练数据；示例地图有固定标签。

## 三、内外接力与灾情重调度

- [x] 外部段：药店候选（高德周边搜索或示例）→ 指挥员确认物资点 → 路线 → 社区大门，显示预计耗时；接口失败时说明原因，不用直线冒充导航。
- [x] 内部段：与外部段共用同一个出入口 ID；Dijkstra 走用户确认的路网；交接完成前不开始配送。
- [x] 内涝：按演练时钟逐步涨水，达阈值发结构化封路事件；可查看水深、阈值与触发时刻（点路段）。
- [x] 重调度：识别受影响任务、保留可继续安排；生成候选并校验可达性/库存/运力/时限；不可行时说明缺哪项条件；仅内部封路且接驳点可用时保留外部安排。
- [x] 确认前保持原派单、受阻 Agent 原地等待；确认后按演练时钟模拟接单、移动、交接、送达并回写状态。
- [x] 保存原方案、封路事件、确认记录与执行结果；支持重置演练。
- [x] AI 与 Agent 分工：规则规划器生成并校验候选，AI（可选）只比较与解释，改派仍由指挥员确认。
